# Contribuição

1. Uma branch por alteração; abra pull request com objetivo e evidências.
2. Todo fato novo em `data/` precisa de fonte em `data/sources.json` (URL https e data de acesso).
3. Rode `npm test` antes do commit (valida dados, fórmulas e renderização de todas as telas).
4. Não inclua dados internos fora de `data/internal/` e nunca em repositório público.
